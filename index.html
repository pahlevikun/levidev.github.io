Levidev Studio

Levidev Studio is a small set of apps and agent skills for work that already lives on your computer. The tools review a change, turn a page into text you can keep, or walk a coding agent through a check before anything is called done.

One of them shows each CV hunk before a PDF exists. One converts a page to Markdown. One opens text tools at the cursor on a Mac. The skills write SVG files from colors the repo already has, revise a sentence in another language, or keep an agent on a route it can prove.

You choose a single job, then install it, get the release, or read the source. This page does not ask for an account, and it does not run the tools for you.

What we build

These are the studio's tools, not six service lines.

Where the tools stay

  • Levistack

    Guide a coding agent through a checked workflow. It does not mark a step done without a check.

  • ApplyDiff

    Review CV changes before exporting a PDF. It does not submit applications or invent numbers.

  • mdz

    Turn a web page into Markdown. Check the repository for where a fetched page is processed.

  • Sorot

    Open text tools at your cursor on Mac. Check the repository for what stays on the Mac in the current build.

  • Logo Kit SVG

    Create four SVG logo files from your repo's colors. It does not invent a palette when the repo already has one.

  • Polyglot Copywriter

    Revise source text with language-specific writing guidance. An instruction not to add facts is not a guarantee of every model output.

  • seatpack

    Copy Chrome profiles and Cursor, VS Code, and Android Studio plugins when you change Macs. An account that is already signed in stays in place.

  • seatsweep

    Scan a Mac account and delete only the categories you name. It does not erase the Mac, delete the user, or sign out of iCloud.
