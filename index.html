Levidev Studio

Levidev Studio is a small set of apps and agent skills for work that already lives on your computer. The tools review a change, turn a page into text you can keep, or walk a coding agent through a check before anything is called done.

One of them shows each CV hunk before a PDF exists. One converts a page to Markdown. One opens text tools at the cursor on a Mac. The skills write SVG files from colors the repo already has, revise a sentence in another language, or keep an agent on a route it can prove.

You choose a single job, then install it, get the release, or read the source. This page does not ask for an account, and it does not run the tools for you.
