Wherethetoolsstay

The tool stays where you are working. This page points to each one; it does not run them.

Apps and agent skills for reviewing changes, working with text, and guiding coding agents. Install one, or read the source, and leave the rest.

    Levistack

    Agent skill · Install

    Guide a coding agent through a checked workflow.

    It does not mark a step done without a check.

    ApplyDiff

    Local app · Install

    Review CV changes before exporting a PDF.

    It does not submit applications or invent numbers.

    mdz

    CLI · MCP · extension · Install

    Turn a web page into Markdown.

    Mac · In development

    Open text tools at your cursor on Mac.

    Logo Kit SVG

  6. 06

    Polyglot Copywriter

    Agent skill · Install

    An instruction not to add facts is not a guarantee of every model output.

  7. 07

    seatpack

    Agent skill · Install

    Copy Chrome profiles and Cursor, VS Code, and Android Studio plugins when you change Macs.

    An account that is already signed in stays in place.

    →
  8. 08

    seatsweep

    Agent skill · Install

    Scan a Mac account and delete only the categories you name.

    It does not erase the Mac, delete the user, or sign out of iCloud.
