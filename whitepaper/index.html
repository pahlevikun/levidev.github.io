Where the tools stay

The tool stays where you are working. This page lists the studio's tools and points to each one. It does not run them.

Apps and agent skills for reviewing changes, working with text, and guiding coding agents. Install one, or read the source, and leave the rest.

Levistack

Agent skill · Install. Guide a coding agent through a checked workflow. It does not mark a step done without a check.

ApplyDiff

Local app · Install. Review CV changes before exporting a PDF. It does not submit applications or invent numbers.

mdz

CLI · MCP · extension · Install. Turn a web page into Markdown. Fetching a page and keeping the result local are different steps. Check the repository for network behavior.

Sorot

Mac · In development. Open text tools at your cursor on Mac. Check the repository for what stays on the Mac in the current build.

Logo Kit SVG

Agent skill · Install. Create four SVG logo files from your repo's colors. It does not invent a palette when the repo already has one.

Polyglot Copywriter

Agent skill · Install. Revise source text with language-specific writing guidance. An instruction not to add facts is not a guarantee of every model output.

seatpack

Agent skill · Install. Copy Chrome profiles and Cursor, VS Code, and Android Studio plugins when you change Macs. An account that is already signed in stays in place.

seatsweep

Agent skill · Install. Scan a Mac account and delete only the categories you name. It does not erase the Mac, delete the user, or sign out of iCloud.

Open the tool's page, then install it, get the release, or read the source. Check each repository for its license and data handling.
